# Financial Intelligence Lab · v0.1.0

First official public source release of an **original, reproducible lab using only invented data**.

## Included

- Original fictional financial inputs, revenue/cost/margin and budget variance reporting.
- Source-controlled calculations, reproducible synthetic fixtures and automated CI tests.
- Offline HTML report and documentation for BI-style semantic modeling.
- A separately generated [interactive portfolio demo](https://dicureck.github.io/?demo=finance#lab) with filtering and CSV export.

## Verification

This version is created only after the source at the exact tagged commit passes the repository's **Lab CI** GitHub Actions workflow. The workflow covers the lab's documented automated checks.

## Limitations

No client financial records, audited accounting conclusions, or native Power BI/Tableau workbook. Online portfolio totals are independent of repository fixtures.
